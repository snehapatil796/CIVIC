# CIVIC – Smart Citizen Grievance Management System

## About the Project
CIVIC is an AI-powered Smart Citizen Grievance Management System designed to simplify complaint registration, categorization, prioritization, and resolution.

## Key Features
- AI-powered automatic complaint categorization.
- Automatic priority detection.
- Separate login for different user roles.
- Citizen complaint registration and tracking.
- Technical issue identification.
- Admin dashboard for complaint management.

## Technology Stack
- Frontend: React, TypeScript
- Backend: Node.js
- AI: Google Gemini

## Objective
To improve communication between citizens and authorities through intelligent complaint management and faster resolution.

Developed as a project to make grievance management smarter and more accessible.
